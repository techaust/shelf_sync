### What to build
Follow [m2.0-plan.md](m2.0-plan.md) §1 "m2.3-storage-settings":
1. **Settings** in `db/settings.py` (append to the per-key validator table): `s3_endpoint` (`""` = AWS; otherwise an `https` URL, with `http` allowed only to `127.0.0.1` or `localhost`, for the later moto stack; no userinfo, query or fragment); `s3_region` `^[a-z0-9-]{2,32}$` (default: find it in 04 or 11; if none is decided, default `""` and require it before m2.7's Test); `s3_bucket` `^[a-z0-9][a-z0-9.-]{1,61}[a-z0-9]$` (default `""`); `keep_previous_files` 1 (1–5); `download_link_template` default `[amazon_s3 object="{key}"]`, `{key}` exactly once, at most 200 characters, no line break. Check 03 SET-02, 04 and 11 for any value already decided and use it; say in the report where each default came from.
2. **Secrets** `s3-rw-key-id`, `s3-rw-secret`, `s3-ro-key-id`, `s3-ro-secret` (m2.1 already put them in `OWNED_SECRET_NAMES`): key ID `^[A-Za-z0-9]{16,128}$`, secret `^[A-Za-z0-9/+=]{16,128}$`; masked like m2.1's (`prefix + "••••" + last 4`, never the length); registered with `redact` when set and at start-up (extend m2.1's start-up registration).
3. **API** (behind the guard, in the route walk): `GET /api/settings/storage` → the settings plus `{rw: {access_key_id: masked|null, secret_access_key: masked|null}, ro: {…}}`; `PUT /api/settings/storage` (all settings required, unknown fields refused) → what was saved; `PUT /api/secrets/s3-rw` and `PUT /api/secrets/s3-ro` `{access_key_id, secret_access_key}` (always a pair; both entries written, or neither: on a failure delete the one written) → 204; `DELETE` on both paths → 204. 503 `secrets_unavailable` on a Credential Manager failure. **No** Test route.
4. **Strings:** proposed 13 wording in the report.

### Tests
The field limits; unknown fields; the pair rule (a fake secret store failing on the second `set` leaves nothing); masks; no raw value in any GET body (scan with known values); every secret through every log path (`test_never_logged.py`); the guard and the route walk; a `-m windows` test with a throwaway service.
