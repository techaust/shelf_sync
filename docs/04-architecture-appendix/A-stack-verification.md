# 04-A: Stack and platform verification

Every library and platform claim the design relies on, with its status and source.
- **Verified:** checked against the named source on the date given.
- **Known:** long-standing, widely documented behaviour, taken from that documentation but not re-fetched on this date. It's re-checked with Context7 when the milestone that uses it starts.
- **To verify:** treated as unknown until the named step. Nothing marked "to verify" is presented as fact elsewhere.
